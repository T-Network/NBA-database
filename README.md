# NBA Analytics

A personal NBA data analytics project built to explore player performance under custom game conditions.

The project will collect NBA game data from sources such as Basketball Reference, store the data in a relational database, and allow player performances to be analysed using SQL and Python.

## Planned Features

- Automatically collect NBA player and game data
- Store player, team, game, and performance data in SQL
- Filter performances by minutes played
- Set minimum qualifying game requirements
- Calculate per-game statistics
- Calculate shooting efficiency and advanced metrics
- Rank and compare players
- Analyse different seasons and game conditions
- Eventually provide an interactive dashboard for exploring the data
